# Server_Manage_Plugin (Cacti)

Huawei servers meet industry management standards and are compatible with various types of third-party management software.This project contains a variety of third-party plug-ins.

# 华为服务器管理插件（Cacti）

通过 SNMP 协议连接华为服务器 iBMC（机架服务器管理系统）以及 MM910（刀片服务器机箱管理模块）实现华为服务器的监控，并在Cacti中绘制相应的监控图表。

详细使用说明参见：
https://github.com/jhzzzz/Server_Manage_Plugin/tree/master/Cacti_Plugin
